Document tags

Tags mark what a page contains, on top of the built-in {{ builtin_tags|join(', ') }}, which describe what a page is. A page carries a tag when that tag's pattern is found in the page's extracted text. Once a tag exists, every reviewer can scope a rule to it under Document scope on the Rules page. A tag shown on a document or a page is clickable: it lists the fields it matched, and jumps to the page with the field boxed, so a pattern can be checked rather than trusted. {% if not is_admin %}
Only administrators can add or change tags. {% endif %}
